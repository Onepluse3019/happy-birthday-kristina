КАК ПОДГОТОВИТЬ САЙТ

1. Открой папку images.
2. Замени файлы:
   hero.jpg — главная фотография или красивый фон.
   photo-1.jpg — ваша главная совместная фотография.
   photo-2.jpg, photo-3.jpg, photo-4.jpg — другие ваши фотографии.
   flowers.jpg — фотография ромашек или хризантем.

3. Названия файлов должны остаться такими же.

4. Открой index.html двойным нажатием.

ТЕКСТ
Текст можно менять в файле index.html через обычный Блокнот или VS Code.
